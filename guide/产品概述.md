# NewsC 产品概述

> 每日一站，洞察全网。

## 定位

个人化内容聚合消费平台：多源采集（RSS / YouTube / B 站等）→ 本地 PostgreSQL → 独立 `intelligence` 模块（Mock / OpenClaw）→ Next 专栏阅读。

## 架构（模板 1 · 6→1）

```
collectors → orchestrator → PG(newsc)
                 ↓
           intelligence (Provider)
                 ↓
            apps/web（晨报编辑台）
```

## 前端心智

极简阅读工具风：今日洞察为门面，摘要流为肌肉，详情嵌入为深度，标记、划选笔记与问 AI 为侧翼；「事件」「数据」为检索驱动的专题（时间轴 / 宏观指标）；「订阅」管理日报路径 / 网页 / 社媒 / B 站·YouTube（增删改、启停），「设置」保留采集运维。详见 [笔记.md](./笔记.md)、[事件与数据.md](./事件与数据.md)。

## 生命周期

```bash
cp .env.example .env
./scripts/start.sh
./scripts/verify.sh
./scripts/stop.sh
```

安装后可用统一 CLI（HTTP 调 orchestrator，见 ADR-006）：

```bash
pip install -e .
newsc health
newsc pipeline run rss
newsc ai process --limit 20
newsc vault status
newsc pipeline run sources
newsc pipeline run insight --force
```
