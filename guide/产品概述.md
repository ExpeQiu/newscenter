# NewsC 产品概述

> 每日一站，洞察全网。

## 定位

个人化内容聚合消费平台：多源采集（RSS / YouTube / B 站等）→ 本地 PostgreSQL → 独立 `intelligence` 模块（Mock / OpenClaw）→ Next 专栏阅读。

## 架构（模板 1 · 6→1）

```
collectors → orchestrator → PG(newsc)
                 ↓
           intelligence (Provider)
                 ↓
            apps/web（晨报编辑台）
```

## 前端心智

极简阅读工具风：今日洞察为门面，摘要流为肌肉，详情嵌入为深度，标记与问 AI 为侧翼。

## 生命周期

```bash
cp .env.example .env
./scripts/start.sh
./scripts/verify.sh
./scripts/stop.sh
```
