# 笔记（划选入库）

## 与收藏的区别

| | 收藏 | 笔记 |
|---|---|---|
| 对象 | 整篇条目（星标） | 划选摘录 |
| 组织 | 单一列表 | 可自定义栏目 |
| 入口 | 「收藏」Tab | 「笔记」Tab |

整篇备注仍走 `marks.note`，与本功能无关。

## 交互

1. 在**内容详情**（摘要/正文）或**日报**正文划选文字
2. 桌面：右键 → 选择栏目（或新建栏目）
3. 触控：划选后点浮动「加入笔记」
4. 在「笔记」Tab 浏览、改名栏目、删除摘录

## API

- `GET/POST /note-columns` · `PATCH/DELETE /note-columns/{id}`
- `GET/POST /notes` · `DELETE /notes/{id}`

首次访问栏目列表时自动种子「默认」栏目；不可删除最后一个栏目。

## 日志键

`column_id` / `note_id` / `source_kind` / `item_id`
