# NewsC 架构一页

```
collectors (rss / youtube / bilibili)
        │
        ▼
orchestrator FastAPI :8787  ── REST ──► apps/web :3000
        │
        ├── pipeline → PostgreSQL `newsc`
        │
        ├── POST /digests/push ← digest-CLI (OpenClaw / Hermes HTML)
        │
        └── intelligence.worker
                 │
                 ├─ MockProvider（默认）
                 └─ OpenClawProvider → Gateway :18789
```

关键路径日志字段：`run_id` / `job_id` / `content_hash` / `provider` / `source`（日报推送）。
