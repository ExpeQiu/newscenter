# NewsC 架构一页

```
collectors (rss / youtube / bilibili) ──HTTP ingest──┐
newsc CLI (ops / vault / sources) ──────────────────┤
digest-CLI (vault 主 / push 兼容) ──────────────────┤
                                                    ▼
                              orchestrator FastAPI :8787  ── REST ──► apps/web :3000
                                        │
                                        ├── pipeline → PostgreSQL `newsc`
                                        │
                                        ├── digests vault ← digest-sources.yml
                                        │
                                        └── intelligence.worker
                                                 │
                                                 ├─ MockProvider（默认）
                                                 └─ OpenClawProvider → Gateway :18789
```

关键路径日志字段：`run_id` / `job_id` / `content_hash` / `provider` / `source`（日报来源 id）。

统一入口见 [ADR-006](../ADR/006-unified-newsc-cli.md)。
