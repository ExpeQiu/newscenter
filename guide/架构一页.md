# NewsC 架构一页

```
collectors (rss / youtube / bilibili / social) ──HTTP ingest──┐
newsc CLI (ops / vault / sources) ─────────────────────────────┤
digest-CLI (vault 主 / push 兼容) ─────────────────────────────┤
                                                               ▼
                              orchestrator FastAPI :8787  ── REST ──► apps/web :3000
                                        │
                                        ├── pipeline → PostgreSQL `newsc`
                                        │
                                        ├── digests vault ← digest-sources.yml (+ .local.yml)
                                        │
                                        ├── insight retrieve ← insight-queries.yml（事件/宏观）
                                        │
                                        └── intelligence.worker
                                                 │
                                                 ├─ MockProvider（默认 / verify）
                                                 ├─ MinimaxProvider（推荐真服务）
                                                 └─ OpenClawProvider → Gateway :18789
```

关键路径日志字段：`run_id` / `job_id` / `content_hash` / `provider` / `source`（日报来源 id）/ `query_id`（事件与数据检索）。

统一入口见 [ADR-006](../ADR/006-unified-newsc-cli.md)。
个人日报目录写 `digest-sources.local.yml`（gitignore），与仓库内 `local-demo → daily/` 合并。
事件与数据查询写 `insight-queries.local.yml`，见 [事件与数据.md](./事件与数据.md)。
MiniMax 见 [ADR-003](../ADR/003-mock-first-ai-provider.md)。
