# 事件与数据

检索驱动的「事件」时间轴与「数据」指标面板。

## 心智

| Tab | 路由 | 内容 |
|-----|------|------|
| 事件 | `/events` | 全球 / 中国 / 行业 / 企业重要事件，按日分组时间轴 |
| 数据 | `/data` | 全球 / 中国宏观 + **金融端** + 行业（房地产、AI 等） |

内容不进今日洞察正文，也不走日报 vault。

## 查询目录

- 基线：仓库根 [`insight-queries.yml`](../insight-queries.yml)
- 本机覆盖：`insight-queries.local.yml`（gitignore；见 `insight-queries.local.yml.example`）
- 合并规则：按 `id` 覆盖字段；`deleted: true` 移除基线项

事件项：`kind: event` + `dimension` + `query` + `refresh_interval`  
宏观项：`kind: macro` + `scope` + `indicator_id` + `label` / `unit` + `query`  
金融端：`scope: china` + `industry: 金融`（出现在「全部 / 中国」）  
行业：`scope: industry` + `industry: 房地产|AI|…`（出现在「行业」Tab）

## 管线

```bash
# Mock 验收（默认 AI_MOCK_MODE=true）
newsc --format json pipeline run insight --force
# 仅事件 / 仅宏观
newsc pipeline run insight --force --kind event
newsc pipeline run insight --force --kind macro
```

HTTP：`POST /pipelines/insight/run?force=true&kind=all`

流程：加载查询 → 按周期跳过未到期 → Provider `retrieve_events` / `retrieve_macro` → upsert `insight_events` / `macro_*` → 光标写入 `control_settings.insight_cursors`。

日志关键字：`insight_retrieve_start` / `insight_event_query` / `insight_macro_query` / `insight_retrieve_done`。

## API

- `GET /events?dimension=&industry=&entity=&from=&to=&limit=`
- `GET /events/{id}`
- `GET /macro/indicators?scope=&industry=`
- `GET /macro/observations?indicator_id=`
- `GET /macro/snapshot` — 数据页首屏

## 验收

1. `alembic upgrade head`（含 `0007`）或 `scripts/start.sh` 自动建表
2. 重启 orchestrator 后：`newsc pipeline run insight --force`（或设置页「立即检索」）
3. 打开 `/events`、`/data` 可见入库内容；MiniMax 真模式会写真实结构化结果，空结果会重试/降级 Mock
4. 再跑一次 `--force` → 同 period / 同 hash 去重，`inserted` 接近 0
5. 定时：重新执行 `bash scripts/install-pipeline-sources-launchd.sh` 后，15 分钟管道末尾会跑 `insight`（`force=false`，按 refresh_interval）
